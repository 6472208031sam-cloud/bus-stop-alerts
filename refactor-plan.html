Item 1: Shared Core (bus-core.js)

What

Extract the 88 identical functions (e.g. distanceMeters, triggerArrival, sendNtfy, onPosition, logging, native bridge) into a single bus-core.js file. Both apps load it via <script src="bus-core.js">.

Steps

  1. Diff each of the 88 function bodies (not just names) between the two apps to confirm they're truly identical
  2. Create bus-core.js with the shared functions, verbatim — zero logic changes
  3. In index.html: delete the 88 duplicates, add script tag. Keep 10 bus-only functions inline.
  4. In st-cecilia.html: delete the 88 duplicates, add script tag. Keep 8 stc-only functions inline.
  5. node --check on all three files
  6. Deploy to a preview branch, verify both apps load and function
Risk: A function with the same name but subtly different body would break one app. Mitigation: body-level diff before extracting (step 1).

Time: 3–4 hours

Steps

  1. Extract each array to its JSON file (scripted, byte-exact)
  2. Replace inline arrays with fetch() calls
  3. Gate app initialization behind Promise.all() — show "Loading route..." until data arrives
  4. St Cecilia PM mode still reverses the route in code (.slice().reverse()) — that logic stays
  5. Verify both apps load correctly, routes render identically
Risk: Async loading changes startup order. If map renders before data arrives → blank screen. Mitigation: Promise.all() gate (step 3).

Time: 2–3 hours

Item 3: Version Deploy Script

What

A deploy.sh script that stamps the version in one command:

./deploy.sh 6.8
# 1. Sets APP_VERSION='6.8' in index.html
# 2. Sets APP_VERSION='6.8' in st-cecilia.html
# 3. Updates version badges in home.html
# 4. Runs node --check on all files
# 5. Commits and pushes

This replaces manual find-and-replace, making it impossible for the badge and variable to diverge again.

Time: 30 minutes
